# Logistics Operations BI

## Project Overview

An industry-focused logistics operations analytics project using Excel, Power Query, Power BI, and DAX to evaluate operational performance, fleet efficiency, costs, and delivery performance.

## Project Objective

To transform logistics operations data into reliable business insights and decision-support dashboards for operational management.

## Project Workflow

1. Project Setup
2. Data Foundation
3. Validation
4. Business Design
5. BI Engineering
6. Analysis
7. Dashboard
8. QA & Validation
9. Documentation
10. GitHub / Portfolio
11. Interview Ready

## Tools

- Excel
- Power Query
- Power BI
- DAX
- Python — supporting audit/validation only
- Git / GitHub

## Dataset

Logistics Operations dataset obtained from Kaggle.

Original source data is maintained locally as immutable raw data and is not modified during analysis.
